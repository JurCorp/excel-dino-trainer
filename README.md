# Jurassic Excel - Excel упражнения на русском языке

Интерактивная платформа для изучения Excel формул с поддержкой русского и английского языков.

## 🚀 Возможности

- **Многоязычность**: Поддержка русского и английского языков
- **Русскоязычные формулы**: Работа с формулами типа `=СУММ()`, `=СРЗНАЧ()` и др.
- **Система прогресса**: Сохранение прогресса пользователей в базе данных
- **Аутентификация**: Регистрация и вход пользователей
- **Адаптивный дизайн**: Работает на всех устройствах

## 🛠 Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Формулы**: HyperFormula для вычисления Excel формул
- **База данных**: Supabase (PostgreSQL)
- **Аутентификация**: Supabase Auth
- **Деплой**: Vercel

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/jurassic-excel.git
cd jurassic-excel
```

2. Настройте Supabase (см. [SUPABASE_SETUP.md](SUPABASE_SETUP.md))

3. Обновите ключи в файлах:
   - `logic.js` - замените URL и ключи Supabase
   - `main.js` - замените URL и ключи Supabase

4. Запустите локальный сервер:
```bash
# Используя Python
python -m http.server 8000

# Или используя Node.js
npx serve .
```

## 🌐 Деплой на Vercel

1. Подключите репозиторий к Vercel
2. Настройте переменные окружения в Vercel:
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
3. Деплой автоматически произойдет

## 🎯 Использование

### Для пользователей

1. **Выбор языка**: При первом запуске выберите русский или английский язык
2. **Регистрация**: Создайте аккаунт для сохранения прогресса
3. **Изучение**: Решайте упражнения с Excel формулами
4. **Прогресс**: Ваш прогресс автоматически сохраняется

### Для разработчиков

#### Добавление новых уровней

1. Обновите функцию `getLevelData()` в `main.js`
2. Добавьте новые тексты в объект `texts`
3. Создайте новые упражнения в базе данных

#### Добавление новых формул

1. Обновите объекты переводов в функциях:
   - `translateFormulaToEnglish()`
   - `translateFormulaToRussian()`
