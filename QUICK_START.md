# ⚡ Быстрый запуск Jurassic Excel

## 🚨 Проблема: CORS ошибка

Если видишь ошибку:
```
Access to script at 'file:///...' has been blocked by CORS policy
```

**Это нормально!** Браузер блокирует загрузку файлов через `file://` для безопасности.

## 🔧 Решение: Запусти сервер!

### Способ 1: Через Python (самый простой) 🐍

1. **Открой командную строку:**
   - Нажми `Win + R`
   - Введи `cmd`
   - Нажми Enter

2. **Перейди в папку проекта:**
   ```bash
   cd "C:\Users\rbula\Desktop\jurassic corp\Excel-dino"
   ```

3. **Запусти сервер:**
   ```bash
   python -m http.server 8000
   ```

4. **Открой браузер:**
   - Перейди по адресу: `http://localhost:8000`
   - Или `http://127.0.0.1:8000`

### Способ 2: Через готовый скрипт 🎯

1. **Дважды кликни на файл `start-server.bat`**
2. **Дождись сообщения "Сервер запущен"**
3. **Открой браузер** и перейди на `http://localhost:8000`

### Способ 3: Через Node.js 📦

1. **Открой командную строку в папке проекта**
2. **Запусти:**
   ```bash
   node start-server.js
   ```
3. **Открой браузер** на `http://localhost:8000`
