# Recovery notes — Excel Dino / Jurassic Excel

Дата восстановления: 2026-07-09

## Источник

Проект восстановлен из архива пользователя `Excel-dino — копия.zip` и сверён с публичным Vercel-деплоем `https://didactic-journey-two.vercel.app/`.

## Статус

- Проект является статическим HTML/CSS/JS-приложением, не React/Vite.
- `node_modules` не нужен для запуска.
- `package.json` отсутствует и не обязателен.
- Локальный запуск возможен через простой HTTP-сервер.
- JSON-файлы уровней в `data/` валидны: 12 файлов.
- Основные файлы совпадают с текущим Vercel-деплоем:
  - `index.html`
  - `styles.css`
  - `main.js`
  - `logic.js`
  - `js/level-manager.js`

## Запуск локально

Из корня проекта:

```bash
python3 -m http.server 8123
```

Открыть:

```text
http://127.0.0.1:8123/
```

На Windows, если Python установлен:

```powershell
python -m http.server 8123
```

## Проверка

Проверено в браузере:

- открывается экран выбора уровней;
- видны уровни 1–12;
- уровень 1 открывается;
- формула `=B2+C2+D2` проверяется корректно;
- результат: `397000`.

## Секреты

Файл `.env` из пользовательского архива не включён в чистую рабочую копию.
Не коммитить:

- `.env`
- `.env.local`
- `.env.production`
- Supabase `service_role`
- Vercel/GitHub токены
