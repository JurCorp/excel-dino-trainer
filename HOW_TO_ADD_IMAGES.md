# Как добавить изображения в уровень 12

## Инструкция по добавлению изображений

Чтобы добавить изображение в любое упражнение уровня 12, выполните следующие шаги:

### 1. Подготовьте изображение

- Сохраните изображение в папку `images/` проекта
- Или используйте URL изображения в интернете

### 2. Откройте файл `data/level12.json`

### 3. Найдите нужное упражнение

Найдите объект упражнения по его `id`, например:
```json
{
  "id": "pivot-creating-step2",
  "task": {
    "ru": "...",
    "en": "..."
  },
  ...
}
```

### 4. Добавьте поле `imageUrl`

Добавьте поле `imageUrl` в объект упражнения:

**Вариант 1: Локальный файл**
```json
{
  "id": "pivot-creating-step2",
  "task": {
    "ru": "...",
    "en": "..."
  },
  "imageUrl": "images/pivot-table-insert.png",
  ...
}
```

**Вариант 2: URL из интернета**
```json
{
  "id": "pivot-creating-step2",
  "task": {
    "ru": "...",
    "en": "..."
  },
  "imageUrl": "https://example.com/pivot-table-insert.png",
  ...
}
```

### 5. Сохраните файл

После сохранения изображение автоматически появится в упражнении перед текстом задачи.

## Пример полного упражнения с изображением

```json
{
  "id": "pivot-creating-step2",
  "task": {
    "ru": "# Создание сводной таблицы\n\n## Шаг 2: Вставка сводной таблицы\n\n...",
    "en": "## Creating a Pivot Table - Step 2"
  },
  "imageUrl": "images/pivot-table-insert.png",
  "data": [],
  "resultCell": "",
  "hint": {
    "ru": "...",
    "en": "..."
  },
  "points": 0,
  "explanation": {
    "ru": "...",
    "en": "..."
  }
}
```

## Примечания

- Изображение будет отображаться **перед** текстом задачи
- Поддерживаются форматы: PNG, JPG, GIF, SVG
- Рекомендуемый размер: не более 1920x1080 пикселей
- Для локальных файлов путь указывается относительно корня проекта
